## First preview scope

The owner requested references followed by UI work. `apps/web` now contains a local HTML/CSS/JavaScript design preview with synthetic fixtures: entry/session-ended presentation, project directory, Board, Backlog, task detail and local task creation/state changes. Changes live in memory and reset on reload/exit. No credential form, API requests, permission cache, provider request or business persistence exists. Server-side security is not simulated by client controls.

Frame variants cover ready, loading, empty, generic unavailable, service failure, read-only, conflict, unknown outcome, no active Sprint and AI offline. Conflict/unknown variants do not silently resubmit. Local filtering is labelled Filter tasks; it is not FR-70 server keyword search. Documents/Search/Members currently lead to explicit next-slice placeholders.

Proposed visual direction: warm neutral surfaces, forest-green actions, restrained labels, readable task cards and a narrow-screen single-column Board. “Threadwork” and sample member/project names are provisional presentation copy. Fonts are local system/Georgia; no external assets or fonts are requested. No visual or WCAG target is declared accepted.
